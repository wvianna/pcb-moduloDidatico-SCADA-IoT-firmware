Notas de interoperabilidade:
- O mesmo mapeamento de I/O acima e utilizado como modelo canonico para os tres modos de operacao do firmware: Modbus, MQTT e OPC UA.
- O pino RX/GPIO3 (ED2) acumula duas funcoes: entrada discreta 10002 em runtime e gatilho de setup AP no boot (nivel baixo no boot entra em AP).
- RX/GPIO3 nao e pino de bootstrap; com INPUT_PULLUP, o nivel baixo (switch para GND) forca o AP apenas quando acionado. Disponivel apenas com SERIAL_DEBUG_ENABLED=false (RX livre).
- GPIO15/D8 (ED1) volta a ser somente entrada discreta 10001. GPIO15 continua sendo pino de bootstrap: deve permanecer em nivel baixo no reset para boot normal por flash.
- Modo Modbus: coils/discrete/input/holding registers sao acessados por Modbus TCP/RTU.
- Modo MQTT: discrete_inputs e input_registers sao publicados em JSON; coils e holding_registers sao recebidos por subscriber JSON.
- Modo OPC UA: as configuracoes de endpoint estao disponiveis na interface web de setup; runtime OPC UA permanece reservado para evolucao em plataforma com suporte nativo completo.
